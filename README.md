# 末期腎臟病共享決策

網址：<https://yht5582-source.github.io/Dialysis-SDM/>

單一檔案的靜態網頁（`index.html`），給腎臟科團隊與病人、家屬一起使用：選擇院內血液透析、腹膜透析、居家血液透析、腎臟移植、腎臟保守治療，或停止透析，並同步規劃預立醫療照護諮商（ACP）、預立醫療決定（AD）與 DNR。

## 設計原則

- 先問階段：尚未透析（CKD 4–5 或移植腎衰退）、血液透析中、腹膜透析中，可討論的選項不同。
- 預後先行：以 RPA 2010 第 6 項建議（≥75 歲且 ≥2 項：意外問題「不會意外」、修正版 Charlson ≥8、KPS <40、白蛋白 <2.5）標示「可考慮不透析」；≥75 歲透析前另可算 REIN 分數（開始透析 6 個月死亡率）。預後不明時提供限時嘗試透析。
- 綜合建議：先排除醫療上不建議的選項 → 尊重病人在可行範圍內的選擇 → 未決定時以價值契合度排序；選擇不可行時提出同類替代，移植與限時嘗試會配一個銜接透析模式。SURE ≤3 分判定有決策衝突，不建議當天定案。
- 執行路徑：依選定模式列出準備步驟（通路、導管、訓練、移植評估、安寧照會、停止透析程序等），勾選即記錄日期並寫入 SDM 紀錄。
- 每個選項標示「可行／需評估／不建議」與理由（腹腔、操作能力、照顧者、移植障礙）。
- 價值澄清只在醫療上可行的選項之間比較契合度，不是醫療建議。
- 不論選哪條路，都同步檢視 ACP／AD／DNR、醫療委任代理人與期望臨終地點。
- 每次填寫都留下時間紀錄，可一鍵複製「SDM 紀錄」貼到病歷。

## 分頁

1. 引導評估：階段、腎功能與急迫性（KDIGO 2024：eGFR <15–20 或 KFRE 2 年 >40% 進入準備期）、預後、移植與居家治療可行性、選項判斷、預立醫療下一步
2. 選項比較：五種選擇並排比較，另有限時嘗試透析與停止透析
3. 價值澄清：9 項病人在意的事 × 各選項特性
4. 理解確認：10 題是非題與說明
5. 綜合建議與路徑：建議、SURE 決策準備度、執行路徑核對清單
6. 成效評估：決策衝突量表（DCS 16 題問句版，討論前／做決定時）、決策準備量表（PrepDM，討論後）、決策後悔量表（DRS，決定後 3–6 個月），OHRI 公布的中文版、題目照原文；自動計分並寫入 SDM 紀錄，可複製一列（Tab 分隔）貼到 Excel 累積成效
7. ACP・AD・DNR：安寧緩和醫療條例與病人自主權利法對照、諮商流程、停止透析程序、溝通句型
8. 流程總覽
9. 示例病例（虛構教學資料）
10. 參考文獻與信效度：每個評估工具的驗證狀態

## 評估工具的信效度

| 工具 | 狀態 |
|---|---|
| 意外問題、KPS、修正版 Charlson、REIN、KFRE、SURE | 已發表驗證（REIN 僅內部驗證；SURE 繁中官方譯本未見心理計量驗證） |
| DCS、PrepDM、DRS | 英文版已驗證；使用 OHRI 公布的中文譯本，台灣未見心理計量研究（DCS 問句版的驗證資料手冊註明仍在收集） |
| RPA 第 6 項規則、可行性判斷 | 指引共識或臨床規則，未經前瞻驗證 |
| 價值澄清特性分數、綜合建議演算法、理解確認 10 題 | 未驗證（教學性近似／僅內容效度），用來引導討論 |

## 開發

決策邏輯集中在 `index.html` 的 `/*ENGINE-START*/ … /*ENGINE-END*/` 區塊，可在 Node 單獨測試：

```bash
node tests.cjs
```

## 醫療安全聲明

本工具供醫療團隊與病人、家屬共同討論使用，不取代臨床判斷、院內 SDM 流程與法律諮詢。法規與健保規定會修訂，簽署文件前請以主管機關最新公告為準。資料只存在使用者瀏覽器的 localStorage，不會上傳；請勿輸入可識別病人身分的資訊。
