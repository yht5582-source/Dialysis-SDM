# 末期腎臟病共享決策

單一檔案的靜態網頁（`index.html`），給腎臟科團隊與病人、家屬一起使用：選擇院內血液透析、腹膜透析、居家血液透析、腎臟移植、腎臟保守治療，或停止透析，並同步規劃預立醫療照護諮商（ACP）、預立醫療決定（AD）與 DNR。

## 設計原則

- 先問階段：尚未透析（CKD 4–5 或移植腎衰退）、血液透析中、腹膜透析中，可討論的選項不同。
- 預後先行：以 RPA 2010 第 6 項建議（≥75 歲且 ≥2 項：意外問題「不會意外」、高共病、功能明顯受損、白蛋白 <2.5）標示「可考慮不透析」；預後不明時提供限時嘗試透析。
- 每個選項標示「可行／需評估／不建議」與理由（腹腔、操作能力、照顧者、移植障礙）。
- 價值澄清只在醫療上可行的選項之間比較契合度，不是醫療建議。
- 不論選哪條路，都同步檢視 ACP／AD／DNR、醫療委任代理人與期望臨終地點。
- 每次填寫都留下時間紀錄，可一鍵複製「SDM 紀錄」貼到病歷。

## 分頁

1. 引導評估：階段、腎功能與急迫性（KDIGO 2024：eGFR <15–20 或 KFRE 2 年 >40% 進入準備期）、預後、移植與居家治療可行性、選項判斷、預立醫療下一步
2. 選項比較：五種選擇並排比較，另有限時嘗試透析與停止透析
3. 價值澄清：9 項病人在意的事 × 各選項特性
4. 理解確認：10 題是非題與說明
5. ACP・AD・DNR：安寧緩和醫療條例與病人自主權利法對照、諮商流程、停止透析程序、溝通句型
6. 流程總覽
7. 示例病例（虛構教學資料）
8. 參考文獻

## 開發

決策邏輯集中在 `index.html` 的 `/*ENGINE-START*/ … /*ENGINE-END*/` 區塊，可在 Node 單獨測試：

```bash
node tests.cjs
```

## 醫療安全聲明

本工具供醫療團隊與病人、家屬共同討論使用，不取代臨床判斷、院內 SDM 流程與法律諮詢。法規與健保規定會修訂，簽署文件前請以主管機關最新公告為準。資料只存在使用者瀏覽器的 localStorage，不會上傳；請勿輸入可識別病人身分的資訊。
